** Decision

There is no ASP source runner. =gerbil test= is the public executable boundary
and =:clan/testing= is the Scheme framework boundary. Their existing regex,
feature, quiet/verbose, file, directory, and recursive-directory arguments are
used without translation.

** ASP contribution

=src/testing/extension.ss= contains only POO profile composition.
=src/testing/extension.ss= maps profiles to caller-supplied test paths without
reading test source, scanning directories, or inferring a test closure.
=src/testing/performance.ss= emits an observation receipt around a supplied
thunk; it does not own suite execution.

This split avoids the former double ownership of selection, loading, reporting,
and source scope while retaining declarative memory, performance, debug-trace,
and resource extensions.

** Performance rule

An explicit upstream test selection must remain explicit. ASP profile
projection may add bounded instrumentation, but may not turn one file into a
repository-wide run or append a policy source scan. Any performance claim must
measure the supplied thunk and report its limits rather than simulate gxtest.
