#+TITLE: 31.06 POO Testing Resource Profiles
#+STARTUP: overview

* Purpose

Memory stability and machine performance are optional POO extensions around
ordinary upstream =gerbil test=. They are not source macros, a second testing
framework, or metadata inferred by scanning test files.

* Declaration

The ASP testing interface enables memory, performance, debug-trace, and
shared-resource profiles by default. A project specializes and maps profiles
with ordinary gerbil-poo composition:

#+begin_src scheme
(import :clan/poo/object
        :asp-gerbil-scheme/build-api)

(def +testing+
  (testing-interface-map-profile
   +asp-testing-interface+
   "t/large-project-test.ss"
   (.cc +testing-memory-profile+ maxHeapMiB: 2048)))
#+end_src

The user does not pass =max-heap= on the command line. The POO slot is
projected at the explicit process boundary before the upstream test loads.
=testing-interface-run-test!= delegates the exact path to =gerbil test= and
does not discover files, load suites, schedule batches, or report results.

* Machine performance

The default performance profile identifies upstream wall timing through
=:clan/timestamp= and managed-heap observation through ASP's benchmark memory
library. Its metric set includes wall time, CPU time, allocation, GC, and
managed heap. A test may use =.cc= to add scenario budgets or remove the
profile entirely with =.remove=.

* Failure semantics

A positive =maxHeapMiB= is translated internally to Gambit's startup-time
=-:max-heap=<N>M= option. Heap exhaustion terminates the native test process
instead of allowing an agent-written test to consume the host indefinitely.
Observation receipts do not pretend to be limits: the limit is applied at
process startup, while metrics describe the completed native operation.

* Acceptance

- default 1024 MiB and per-test overrides project to exact native argv;
- POO removal deletes both the default profile and its test bindings;
- the adapter delegates one explicit path to =gerbil test=;
- a clean native build contains no source-metadata profile parser;
- extension and project policy tests pass through native gxtest.
