#+TITLE: 31.02 Native Build Ownership
#+OPTIONS: toc:2 num:nil

* Decision

The former native target stage adapter is removed. It duplicated responsibilities
already owned by =clan/building= and =std/make=: package Graph storage,
currentness prediction, stage ordering, clean behavior, and package compile
commands.

The production path is now direct:

#+begin_src mermaid
flowchart LR
  Script["build.ss
PackageSpec Graph + deps"]
  Clan["init-build-environment!"]
  Make["std/make"]
  Output["native library artifacts"]

  Script --> Clan --> Make --> Output
#+end_src

There is no =src/build-api/native-build.ss=,
=src/build-api/native-build-spec.ss=, =src/build-api/package-native-plan.ss=,
or =src/build-api/project-build.ss=.

* Ownership

| Concern | Owner |
|---------+-------|
| Package identity and acquisition | =gerbil.pkg= / =gxpkg= |
| Library Graph and logical dependencies | root =build.ss= |
| Provider executable Graph | =provider-package-spec.ss= / =build-provider.ss= |
| Native import dependency resolution | =std/make= |
| Native currentness and clean | =std/make= |
| Release, optimized, and debug lowering | upstream build entrypoint |
| Selected test closure | GxTest testing modules |
| Build observations and scenario values | optional =src/building/= library |

A receipt may record that =std/make= ran. It must not skip the call, declare a
target current, split the package Graph into ASP-owned stages, or repair native
artifacts.

* Project commands

Native compile, spec, and clean commands belong to =build.ss=. The reusable
project CLI exposes test selection only; it no longer provides a second
compile/spec/clean route.

#+begin_src sh
gxpkg env gxi ./build.ss spec
gxpkg env gxi ./build.ss compile
gxpkg env gxi ./build.ss clean
#+end_src

* Regression contract

=t/package-build-contract-test.ss= asserts that the root entry retains
=init-build-environment!=, =deps:=, native =all-gerbil-modules= defaults, the
POO =product-entry-modules= option for the executable provider closure, and
the internal cold source bootstrap. It
also asserts that the retired duplicate owner files remain absent.
