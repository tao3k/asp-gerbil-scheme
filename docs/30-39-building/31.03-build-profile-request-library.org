* 31.03 Optional Build Value Library
:PROPERTIES:
:JD_ID: 31.03
:STATUS: implemented
:OWNER: src/building
:RELATED: 31.01, 31.02
:END:

** Purpose

=src/building/= provides POO-native, functional values for tests, scenario
composition, receipt formatting, and experiments. =BuildProfile= and
=BuildRequest= in this library describe those values only. They are not a
package-native profile.

The separate =NativeProfile= in =src/build-api/native-profile.ss= is consulted
by root =build.ss= and =build-provider.ss=. It selects concrete current-system
facts such as macOS/Linux and architecture, prepares the platform pkg-config
search path, and supplies only platform compiler selection for final executable
forms. PackageSpec declares =pkg-config-libs= and =nix-deps=; upstream
=:clan/building= resolves and normalizes the actual compiler/linker flags, and
=std/make= remains the executor.

** Non-ownership rule

The optional library must not:

- translate development or production labels into compiler options;
- intercept release, optimized, or debug flags;
- decide native source/output currentness;
- own a package module catalog;
- schedule, batch, retry, lock, or clean production compilation;
- publish a BuildPlan as proof that a native build completed.

Those responsibilities remain with upstream Gerbil.

** Public use

Downstream callers may import =:asp-gerbil-scheme/build-api= to construct pure
stage/request values for their own application workflows or tests. Crossing an
actual build effect must still call the native owner explicitly.

#+begin_src scheme
(import :asp-gerbil-scheme/build-api)

(def request
  (make-std-builder-request
   "scenario"
   (make-std-builder-profile scenario-builder)
   [["fixture.ss"]]
   (lambda (spec context) #f)
   'fixture-context))
#+end_src

This API is additive data modelling. It is not the normal package build route.

** Acceptance

- Pure value and scenario tests remain green.
- Root and provider cold builds use =NativeProfile= only for current-system
  preparation and delegate dependency flag resolution to =:clan/building=.
- Package build contracts contain no ASP development/production profile,
  BuildPlan admission, or alternate native executor.
