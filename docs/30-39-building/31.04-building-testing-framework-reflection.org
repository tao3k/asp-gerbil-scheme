** Boundary

=std/make= owns the production module graph and compilation. =gerbil test= and
=:clan/testing= own test discovery and execution. ASP does not bridge them
through a private testing-build model.

Optional Building values remain pure POO/functional descriptions. Optional
Testing values remain POO instrumentation profiles. A benchmark observes a
caller-supplied thunk and can attach the performance profile; it never decides
which suites exist or invokes a second source collector.

** Composition

#+begin_src mermaid
flowchart LR
  Package["gerbil.pkg"] --> Building["clan/building"]
  Building --> Make["std/make graph"]
  CLI["gerbil test"] --> Testing["clan/testing"]
  Profiles["ASP POO profiles"] -. limits and observations .-> CLI
  Debug["clan/poo/debug"] -. trace-poo .-> Profiles
#+end_src

The shared invariant is upstream ownership: ASP may compose declarative values
around a native operation, but does not replace native compilation, testing,
selection, cleanup, or reporting.

** Acceptance

1. clean native package build;
2. focused native =gerbil test= execution;
3. POO profile override/removal tests;
4. policy source scope derived from =all-gerbil-modules=;
5. no import of a retired testing framework or runner.
